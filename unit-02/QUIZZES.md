# Ответы к Quiz — Unit 2

Ответы подготовлены по текущим вопросам официального курса. Онлайн-отправка
в Google Developer Profile не выполняется автоматически.

## Pathway 1 — Kotlin fundamentals

1. **False.** Для `25` остаток от деления на 10 равен 5, а второе условие
   сравнивает само число с 5, поэтому строка не печатается.
2. **`x == 5`, `x in 1..5`, `x is Int`.** `x % 5` возвращает число, а не Boolean.
3. **Readability.** Абстракция, наследование и полиморфизм относятся к основным
   понятиям объектно-ориентированного программирования.
4. **`private`, `protected`, `public`, `internal`.** Это четыре модификатора
   видимости Kotlin.
5. **`super`.** Через него вызывают реализацию родительского класса.
6. **Interface.** Интерфейс задаёт свойства и методы, которые должен реализовать класс.
7. **An optional profile picture.** Отсутствующее необязательное изображение естественно
   представить значением `null`.
8. **`?.`.** Safe-call выполняет обращение только для ненулевого объекта.
9. **“A function can be changed to another data type, and vice versa.”** Это неверно;
   функция сама имеет тип и может передаваться или возвращаться как значение.
10. **Lambda expression.** Лямбда является функциональным литералом.

## Pathway 2 — Add a button to an app

1. **Image.** Этот composable отображает изображение.
2. **True.** `Alignment.Center` центрирует по обеим осям.
3. **remember.** Он сохраняет объект между рекомпозициями.
4. **True.** При остановке на breakpoint отладчик показывает значения переменных.
5. **mutableStateOf.** Изменение наблюдаемого значения планирует рекомпозицию.
6. **Column.** Дочерние элементы располагаются вертикально.
7. **Step out.** Команда завершает текущий вызов и возвращается выше по стеку.

## Pathway 3 — Interacting with UI and state

1. **Initial composition.** При первом выполнении Compose строит и запоминает Composition.
2. **True.** Изменения отображаемого состояния применяются через рекомпозицию.
3. **Recomposition.** Compose повторно выполняет затронутые composable-функции.
4. **State.** Состояние — значение, которое может изменяться со временем.
5. **State hoisting.** Состояние поднимается к вызывающему компоненту.
6. **`onNext`.** Это действие переводит фокус на следующее поле.
7. **`kotlin.math.ceil()`.** Функция округляет число вверх.
8. **True.** Layout Inspector позволяет исследовать интерфейс запущенного приложения.
9. **androidTest.** Там хранятся инструментальные UI-тесты.
10. **`@Test`.** Ею помечают и локальные, и инструментальные тестовые методы.
