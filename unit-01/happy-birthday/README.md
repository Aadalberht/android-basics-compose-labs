# Happy Birthday

 Откройте эту папку в Android Studio и дождитесь синхронизации Gradle.
 Выберите устройство Android 7.0+ (API 24+) и нажмите Run.
 Команда сборки: `./gradlew assembleDebug` (JDK 17, Android SDK 35).
 APK: `app/build/outputs/apk/debug/app-debug.apk`.

 Интерфейс: `app/src/main/java/com/example/happybirthday/MainActivity.kt`.
 Тексты: `app/src/main/res/values/strings.xml`. Предпросмотр: `AppPreview`.
