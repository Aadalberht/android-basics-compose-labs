# Прототип визитки

```text
┌───────────────────────────┐
│                           │
│       [Android logo]      │
│           Albert          │
│      Android Developer    │
│                           │
│    ☎  +7 (000) 000-00-00   │
│    ↗  @android_student    │
│    ✉  student@example.com │
└───────────────────────────┘
```

Верхняя группа Profile: Image + два Text в Column по центру.
Нижняя группа Contacts: три Row (Icon + Spacer + Text) в Column.
Spacer с weight распределяет свободное пространство между группами.
Цвет фона #D2E8D4; акценты #006B3C; фон логотипа #073042.
Имя Albert — учебный пример. Контакты намеренно демонстрационные;
перед сдачей их можно заменить в strings.xml.
